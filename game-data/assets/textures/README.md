# Структура папки `assets/textures/`

## `environment/`
Текстуры игрового мира — **не предметы инвентаря**.

| Папка | Содержимое |
|---|---|
| `environment/biomes/` | Тайлы биомов: трава, пустыня, вода и т.д. |
| `environment/structures/` | Спрайт-листы объектов мира: деревья, рудные жилы (используются в TileSet) |

## `items/`
Иконки предметов инвентаря. Каждый файл подключается к соответствующему `.tres` через поле `texture`.

| Папка | Содержимое |
|---|---|
| `items/ores/` | Иконки добываемых ресурсов: уголь, медная руда, железная руда и т.д. |
| `items/materials/` | Слитки, шестерёнки, пластины и прочие промежуточные материалы |
| `items/tools/` | Инструменты и оружие: кирки, топоры, мечи |
| `items/blocks/` | Иконки ставимых блоков: камень, медный блок и т.д. |
| `items/chests/` | Спрайт-листы сундуков (иконки + анимация открытия) |

## `tilesets/`
TileSet-ресурсы (`.tres`) и их текстуры. Используются TileMapLayer в сцене мира.

| Файл | Назначение |
|---|---|
| `TerrainTileSet.tres` | TileSet для слоя биомов (terrain_layer) |
| `ObjectsTile.tres` | TileSet для объектов мира (objects_layer): руды, деревья, блоки |
| `MapOreTileSet.tres` | TileSet для маркеров руд на миникарте |
| `MapOreMarkers.png` | Спрайт-лист маркеров миникарты |

---

## Правила добавления новых текстур

1. **Предмет инвентаря** → кладёшь в `items/<категория>/`, добавляешь в `.tres` файл предмета:
   ```
   [ext_resource type="Texture2D" path="res://assets/textures/items/ores/copper_ore.png" id="2_tex"]
   texture = ExtResource("2_tex")
   ```
2. **Тайл мира** → кладёшь в `environment/` и подключаешь через редактор TileSet.
3. **Новая категория предметов** → создаёшь подпапку в `items/` и дописываешь строку в эту таблицу.
