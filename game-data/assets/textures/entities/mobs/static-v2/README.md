# Все статичные текстуры противников v2

Полный набор из 37 PNG: 27 обычных и крупных мобов, 9 боссов и росток Энта. По одному статичному кадру на существо, без анимации. Все изображения имеют прозрачный фон и жёсткие пиксельные края.

Размеры: обычные мобы и росток 32×32, крупные мобы 48×64, боссы 96×128. Мини-боссов и врагов океана/пляжа в текущих реестрах нет.

`manifest.json` содержит полный список, биомы, имена, размеры и SHA-256 файлов. Галерея с русскими названиями: `docs/generated/enemy_static_v2_gallery.html`. Общий лист: `docs/generated/enemy_static_v2_contact.png`. Галерея открывается с диска без интернета.

Набор создан локальным растровым кодом: нейтральные формы прежнего набора проработаны текстурами материалов и индивидуальными деталями. Скарабей сохранён из предыдущего статичного v2. Это не изображения от image_gen: встроенный генератор не вернул ни одного результата из-за сетевых ошибок. API-ключи не использовались.

Генератор: `tools/pixel_art/generate-enemy-static-v2.mjs`; формы: `tools/pixel_art/enemy-static-shapes-v2.mjs`; скарабей: `tools/pixel_art/draw-scarab-v2.mjs`. Повторное создание: `node tools/pixel_art/generate-enemy-static-v2.mjs`. Требуются Node.js и sharp, установленный в текущем рабочем окружении.

Проверены все 37 текстур: размеры, прозрачность, отсутствие обрезанных краёв, 37 различных изображений и отсутствие идентичных первых кадров из v1. Результаты: `docs/generated/enemy_static_v2_validation.json`.

Старый набор v1 и его анимации сохранены. Статичный v2 пока не подменяет изображения в игре; анимации и подключение v2 — следующий этап по запросу пользователя.
